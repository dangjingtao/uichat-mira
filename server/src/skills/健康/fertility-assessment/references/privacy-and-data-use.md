# 备孕全景评估 — 隐私与信息使用说明

## 简要说明

本服务会使用您在本次对话中主动提供的备孕经历、检查结果、治疗记录和生活方式信息，用于整理当前情况、完成量化评估并生成专属报告。

- 可以使用称呼或化名，不要求提供身份证号、详细住址等与本次评估无关的身份信息；
- 任何问题都可以跳过，不确定或不方便回答时可以直接说明；
- 可以随时停止评估，不需要为了生成报告而补齐全部资料；
- 本 Skill 不单独设计复杂的撤回流程；不再需要时，可使用应用现有的对话删除功能清理本次会话记录；
- 报告中可能包含敏感健康信息，请由评估对象自行妥善保管，不建议未经双方同意公开传播。

## 模型处理说明

本 Skill 使用 Mira 当前已配置的模型完成对话理解和报告撰写。

- 使用本地模型时，内容由本机模型处理；
- 使用云模型时，完成本次评估所需的内容会由当前配置的模型服务商处理；
- 本 Skill 不承诺所有部署环境都只在本机处理，实际处理链路以 Mira 当前 Provider 配置为准。

## 夫妻联合评估

夫妻联合报告会处理双方的健康与生育信息。提供另一位评估对象的信息前，应确认已获得对方同意。

如无法确认，只应提供本人的信息，或改为个人评估。

## 信息边界

本服务遵循以下原则：

```text
主动提供
+ 最少必要
+ 可以跳过
+ 可以停止
+ 处理链路透明
```

本报告用于健康教育、信息整理和就诊准备，不构成诊断、处方或替代生殖专科医生的医疗决策。
