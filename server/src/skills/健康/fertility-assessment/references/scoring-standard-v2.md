# 备孕全景评估 — 评分标准 v2

## 当前版本

- 规则版本：`fertility-rubric-v2.0.0`
- 发布时间：2026-07
- 适用范围：女性个人、男性个人、夫妻双方联合生育力画像
- 目的：帮助用户理解当前信息形成的方向、优先级和资料缺口

本评分不是自然受孕率、临床妊娠率、试管成功率、活产率或疾病概率，也不能替代生殖专科医生结合原始检查资料作出的判断。

## 分数区间

| 分数 | 用户可见含义 | 阅读方式 |
|---|---|---|
| 8.0–10.0 | 优势维持 | 当前证据整体偏有利，继续保持并按需复核 |
| 6.5–7.9 | 总体稳定 | 当前方向较稳定，仍需结合缺失资料阅读 |
| 5.0–6.4 | 建议优化 | 存在可进一步澄清或优化的方向 |
| 3.0–4.9 | 需要关注 | 已有证据提示应优先与专科医生核对 |
| 0–2.9 | 优先评估 | 当前直接证据显示较高关注度，应优先进行专业评估 |

当资料完整度为 0% 时，`5.0` 仅表示中性参考基准，用户界面应显示“参考基准 · 暂不可充分评价”，不能解释为正常或异常。

## 评分由什么组成

每个维度先读取已发布的医学规则，再由报告模型把用户已提供的事实归类到对应 `criterionId`。模型不直接决定分数。

```text
维度基础分
+ 有利证据影响
- 轻度 / 中度 / 高度关注证据影响
→ 依据证据覆盖度计算可靠度
→ 资料不足时向 5.0 中性基准收缩
→ 得到最终 0–10 分
```

默认方向影响值如下；每一项还会乘以该维度中对应 criterion 的权重：

| 证据方向 | 默认影响值 |
|---|---:|
| favorable | +0.80 |
| neutral | 0 |
| mild_concern | -0.75 |
| moderate_concern | -1.45 |
| high_concern | -2.35 |
| unknown | 0 |

最终分数会限制在 `0–10` 范围内，并保留 1 位小数。资料越少，结果越靠近 5.0；明确、直接且高关注的证据仍会保留较高影响。

## 置信度与资料完整度

置信度与分数是两件不同的事。低分不自动等于高置信度，高分也不代表资料充分。

资料完整度按各 criterion 的权重计算，不是简单的“回答了几道题”。

默认置信度标准：

| 置信度 | 条件 |
|---|---|
| 高 | 加权完整度 ≥72%，关键 criterion 覆盖 ≥60%，且至少有 2 条直接证据 |
| 中 | 加权完整度 ≥38%，至少覆盖 1 个关键 criterion，且至少有 1 条直接证据 |
| 低 | 其他情况，包括资料不足、主要为间接推断或关键证据缺失 |

## 重要医学边界

- AMH / AFC 主要用于理解卵巢储备和促排反应，不直接等同卵子质量或自然受孕概率。
- 女性年龄属于时间窗口和卵母细胞背景，不是疾病，也不单独代表最终结局。
- 单一精液参数不构成男性不育诊断。
- DFI、免疫、凝血、NK、封闭抗体等在没有临床指征时不是人人必查，未检测不扣分。
- 具体促排、移植、用药、补充剂、手术和检查方案只能作为就诊讨论问题，不能由本报告替用户决定。

## Profile 校准边界

运行时可以通过 `scoring-profiles.json` 启用经过专业审阅的有限校准，但：

- 默认 `clinical-default` 保持内置规则；
- 校准不能修改用户事实；
- 校准不能把缺失资料当作异常；
- 校准版本必须显示在报告中；
- 未经过专业审阅的 Profile 不应启用重新计算模式。
