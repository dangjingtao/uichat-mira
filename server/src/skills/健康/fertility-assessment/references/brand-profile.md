## 配置来源

运行时读取：

```text
references/report-profiles.json
```

该 Source 可以保存多个已发布模板：

- `activeProfileId`：选择默认模板；
- `profiles.<id>.service`：品牌名、团队名、标语、页脚和交付标签；
- `profiles.<id>.theme`：报告配色；
- 服务档案中的 `reportProfileId`：为单个客户选择另一个已发布模板。

修改 Source 后，新生成的报告会按文件修改时间读取最新配置，不需要修改 TypeScript，也不会改变已经完成的旧报告。

## 配置边界

品牌 Profile 只负责：

- 封面品牌身份；
- 服务团队与交付文案；
- 页眉、页脚；
- 报告配色。

品牌 Profile 不得：

- 修改用户事实；
- 改变访谈轮次或收束逻辑；
- 改写医学评分规则；
- 将低置信度结果包装成确定性医疗结论。
