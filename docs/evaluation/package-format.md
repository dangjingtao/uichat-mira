# Evaluation Package 格式

## 1. 文档范围

本页定义当前 `.zip` 评测包的解析合同。

评测包用于告诉 Mira：

- 使用哪个 Knowledge Base；
- 跑哪些问题；
- 哪些来源视为 gold；
- 是否有参考答案；
- 使用什么运行参数。

它当前**不保存可独立运行的 Knowledge Base 快照**。

## 2. 顶层结构

推荐结构：

```text
evaluation-package.zip
├─ manifest.json
├─ evalset.json
└─ documents/
   ├─ source-a.md
   └─ source-b.txt
```

Parser 也接受以下 evalset 路径：

```text
evalset/evalset.json
dataset/evalset.json
```

文件名匹配不区分大小写。

## 3. `manifest.json`

当前结构：

```json
{
  "datasetName": "example-evaluation",
  "knowledgeBaseId": "default",
  "config": {
    "mode": "retrieve-generate",
    "topK": 10,
    "topN": 5,
    "repeat": 1,
    "concurrency": 1,
    "timeoutSeconds": 300
  }
}
```

### 字段

| 字段 | 必需性 | 当前语义 |
| --- | --- | --- |
| datasetName | 可选 | 缺失时使用 ZIP 文件名 |
| knowledgeBaseId | 实际运行必需 | 必须指向当前 Mira 实例中存在的 Knowledge Base |
| config.mode | 可选 | 仅 `retrieve-generate` 会保留该值；其他值回退为 `retrieve` |
| config.topK | 可选 | 缺失时 8 |
| config.topN | 可选 | 缺失时 3 |
| config.repeat | 可选 | 缺失时 1；执行时至少 clamp 为 1 |
| config.concurrency | 可选 | 缺失时 1；执行时至少 clamp 为 1 |
| config.timeoutSeconds | 可选 | 缺失时 300；执行时至少 clamp 为 1 |

缺少 manifest 时，Parser 可以给部分字段填默认值，但结构校验仍为 `error`，不能启动 Run。

## 4. `evalset.json`

接受两种形态。

### 4.1 数组

```json
[
  {
    "id": "sample-001",
    "question": "Mira 的工具审批如何工作？",
    "expectedAnswer": "具体工具调用需要经过冻结、Policy 和审批。",
    "goldSources": ["tool-runtime.md"],
    "tags": ["tool", "approval"]
  }
]
```

### 4.2 带 `samples` 的对象

```json
{
  "samples": [
    {
      "question": "问题",
      "referenceAnswer": "参考答案",
      "goldSources": ["source.md"]
    }
  ]
}
```

`referenceAnswer` 可作为 `expectedAnswer` 的兼容字段。

## 5. Sample 字段

| 字段 | 必需性 | 当前处理 |
| --- | --- | --- |
| id | 可选 | 缺失时生成 `sample-001` 等 ID |
| question | 必需 | 非字符串或空字符串的条目会被丢弃 |
| expectedAnswer | 可选 | 缺失时为空字符串 |
| referenceAnswer | 可选 | expectedAnswer 缺失时作为兼容来源 |
| goldSources | 可选 | 非字符串数组会归一化为空数组 |
| tags | 可选 | 非字符串数组会归一化为空数组 |

当前没有验证 Sample ID 唯一性。重复 ID 可能影响展示、排序和诊断，不应依赖系统自动修复。

## 6. Gold Source 语义

当前匹配逻辑：

```text
normalize(documentName)
==
normalize(goldSource)
```

归一化仅做：

- trim；
- lowercase。

当前不支持：

- Document ID 匹配；
- Chunk ID 匹配；
- 路径别名；
- 模糊文件名；
- 语义匹配；
- 来源内容校验。

因此 goldSources 应填写 RAG 返回的**准确 documentName**。

例如当前文档名为：

```text
产品说明 V2.md
```

推荐：

```json
"goldSources": ["产品说明 V2.md"]
```

不要只写：

```json
"goldSources": ["产品说明"]
```

## 7. `documents/*`

当前 Parser 对 documents 条目只记录：

- name；
- 从路径名推断的粗类型；
- sizeLabel。

类型推断仅检查路径是否包含：

- `话术`；
- `案例`；
- `规章`；
- 否则为 `未分类`。

当前不会：

- 读取 documents 正文用于评测；
- 将 documents 导入 Knowledge Base；
- 比较 documents 与当前 Knowledge Base 内容；
- 根据 documents 创建冻结索引。

### 自动生成包的占位文件

Mira 自动生成包时，`documents/<name>` 的内容固定为：

```text
Generated by evaluation package generator.
```

所以自动生成 ZIP 只携带文档名称，不携带真实文档正文。

## 8. 可运行条件

Dataset 可以启动 Run，需要同时满足：

```text
manifest 存在
+
documents 至少一个条目
+
至少一个有效 question
+
knowledgeBaseId 存在
+
当前实例能找到该 Knowledge Base
+
没有 validation error
```

Reference Answer 和 Gold Sources 缺失通常只是 warning，不阻止运行，但对应指标可能失去意义。

## 9. 自动生成包

当前自动生成器：

1. 从 `ready + enabled` 文档中随机选取文档；
2. 从文档详情中随机选取 Chunk；
3. 截取归一化后的前 1200 字符；
4. 调用 `evaluation` role 生成 question、expectedAnswer 和 tags；
5. 把当前 documentName 写入 goldSources；
6. 发现重复 question 时整次生成失败；
7. 写出 manifest、evalset 和占位 documents。

当前没有：

- 固定 seed；
- 单条失败重试；
- 人工审阅步骤；
- 自动事实校验；
- 来源正文快照。

自动生成样本应在运行前人工预览，不应因为模型返回 JSON 就视为 gold data。

## 10. 可复现性边界

当前 Run 通过 `knowledgeBaseId` 查询实时本地 Knowledge Base。

因此以下变化都会改变同一 ZIP 的结果：

- 文档增加、删除、启停或改名；
- 文档内容更新；
- Chunking 变化；
- Embedding 模型或维度变化；
- Rerank 配置变化；
- LLM / Provider 变化；
- RAG Runtime 变化。

要比较两次 Run，至少要人工记录：

```text
Mira commit / version
Knowledge Base 内容版本
Document names
Embedding role
Rerank role
llm role
Evaluation ZIP hash
运行参数
```

当前 Package 本身没有保存这些完整环境快照。

## 11. 安全与资源边界

- ZIP 完整读入内存；
- 最大 100 MB；
- JSON 解析失败返回 400；
- 非 ZIP 返回 400；
- 超限返回 413；
- 只允许一个上传文件。

评测包属于本地配置和测试数据。若包含业务问题、参考答案或来源名称，应按敏感项目资料处理。

## 12. 最小示例

`manifest.json`：

```json
{
  "datasetName": "kb-smoke",
  "knowledgeBaseId": "default",
  "config": {
    "mode": "retrieve",
    "topK": 8,
    "topN": 3,
    "repeat": 1,
    "concurrency": 1,
    "timeoutSeconds": 60
  }
}
```

`evalset.json`：

```json
[
  {
    "id": "sample-001",
    "question": "这份资料的核心结论是什么？",
    "expectedAnswer": "填写人工核对后的参考答案。",
    "goldSources": ["准确的文档名.md"],
    "tags": ["smoke"]
  }
]
```

并至少包含：

```text
documents/准确的文档名.md
```

该 documents 文件内容当前不会被 Runtime 使用，但条目缺失会导致结构校验失败。
